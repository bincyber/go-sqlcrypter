## 0.3.0 - 2026-06-02

This release contains minor, backwards incompatible changes.

### Added
* New type `NullEncryptedBytes` for telling `NULL` apart from empty string - [#155](https://github.com/bincyber/go-sqlcrypter/pull/155)

### Changed
* **Breaking Change:** `Init()` now returns an error if called with a nil Crypter - [#146](https://github.com/bincyber/go-sqlcrypter/pull/146)
* **Breaking Change:** `EncryptedBytes.String()` no longer leaks decrypted data - [#146](https://github.com/bincyber/go-sqlcrypter/pull/147)
* awskms provider now supports custom request timeout, rate limiting, and cache settings - [#145](https://github.com/bincyber/go-sqlcrypter/pull/145)
* Upgraded to Go v1.26 and upgraded dependencies - [#129](https://github.com/bincyber/go-sqlcrypter/pull/129)
* Documented aesgcm nonce reuse limit - [#156](https://github.com/bincyber/go-sqlcrypter/pull/156)

### Fixed
* Prevent IV collisions for awskms - [#128](https://github.com/bincyber/go-sqlcrypter/pull/128)
* Prevent panic if crypter is not initialized or called with nil - [#134](https://github.com/bincyber/go-sqlcrypter/pull/134)
* Error handling in Vault provider - [#135](https://github.com/bincyber/go-sqlcrypter/pull/135)
* Prevent panic due to invalid length ciphertext - [#144](https://github.com/bincyber/go-sqlcrypter/pull/144)
