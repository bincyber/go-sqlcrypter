## 0.4.0 - 2026-11-08

This release contains backwards compatible changes. The minimum supported Go version is now **v1.26.10**.

### Added
* aesgcm provider now supports `GODEBUG=fips140=only` - [#162](https://github.com/bincyber/go-sqlcrypter/pull/162)

### Changed
* aesgcm provider now generates nonces with `cipher.NewGCMWithRandomNonce`; the ciphertext format is unchanged and no re-encryption is needed - [#162](https://github.com/bincyber/go-sqlcrypter/pull/162)
* Upgraded to Go v1.26.10 - [#163](https://github.com/bincyber/go-sqlcrypter/pull/163)
* Upgraded dependencies - [#153](https://github.com/bincyber/go-sqlcrypter/pull/153), [#154](https://github.com/bincyber/go-sqlcrypter/pull/154), [#157](https://github.com/bincyber/go-sqlcrypter/pull/157), [#161](https://github.com/bincyber/go-sqlcrypter/pull/161)

### Security
* Upgraded `golang.org/x/net` to v0.60.0 and `golang.org/x/text` to v0.42.0 to fix vulnerabilities reported by govulncheck - [#163](https://github.com/bincyber/go-sqlcrypter/pull/163)
